# Homepage title & meta description

**Where:** Admin → Online Store → Preferences → *Title and meta description*

| Field | Value | Length |
|---|---|---|
| Homepage title | `MAYF Home | Mattresses & Home Furnishings in UAE` | 48 chars |
| Homepage meta description | `Shop mattresses, bedding, beds and made-to-measure curtains at MAYF Home. Free UAE delivery and a 100-night sleep trial on mattresses.` | 134 chars |

The theme adds " | MAYF Home" to page titles that don't already mention MAYF, so this title is
printed exactly as typed.

## Store name (strongly recommended)

**Where:** Admin → Settings → General → *Store name*

Change **"Mayf home" → "MAYF Home"**. The store name still appears in places the theme
doesn't control: checkout, order emails, Google & YouTube channel feed, Shop app. The theme
no longer relies on it for titles and schema, but Google sees all of these.
