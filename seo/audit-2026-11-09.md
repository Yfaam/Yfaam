# MAYF Home — SEO / AIO / GEO Audit

**Site:** https://mayfhome.com (canonical host; `www` 301s to apex)
**Platform:** Shopify, Markets with EN + AR
**Business:** mattresses, bedding, beds, made-to-measure curtains, interior design — UAE
**Audit date:** 9 November 2026
**Pages in sitemaps:** 68 products · 38 collections · 11 pages · 5 articles · 1 blog · full Arabic mirror

---

## 1. Scorecard

| Area | Score | Verdict |
|---|---|---|
| Technical SEO / crawlability | **82 / 100** | Strong. Clean sitemaps, canonicals, hreflang, fast server. |
| On-page SEO | **74 / 100** | Good titles & metas on money pages; thin product copy. |
| Structured data | **55 / 100** | Present but incomplete in exactly the places that earn rich results. |
| Content & E-E-A-T | **58 / 100** | Two excellent page types, but only 5 articles and no About/author layer. |
| AIO readiness (answer engines) | **78 / 100** | AI crawlers allowed, content is extractable, agentic commerce is best-in-class. |
| GEO / off-site authority | **25 / 100** | The bottleneck. No third-party citations, no reviews, no local entity. |
| International / Arabic | **85 / 100** | Genuine full Arabic market, correct hreflang, localised titles. |
| **Overall** | **60 / 100** | Technically healthy site with a visibility problem, not a plumbing problem. |

**Headline:** the site is well built and unusually well prepared for *agentic* commerce, but it is almost invisible as a *brand entity* to Google, to AI answer engines, and to the listicles and forums those engines cite. Fixing schema and product copy is a week of work; fixing authority is a quarter of work — and it is what actually moves AI/GEO visibility.

## 2. What was checked

- Rendered and raw HTML: homepage (EN + AR), product page, mattress collection, curtains collection, curtains service page, mattress finder, blog article.
- `robots.txt`, `sitemap.xml` and all child sitemaps (products, collections, pages, blogs, articles, Arabic mirrors, `sitemap_agentic_discovery.xml`).
- `llms.txt`, `agents.md`, `/.well-known/ucp`.
- Crawler access tested by user-agent for Googlebot, GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot.
- Server response times, redirect behaviour, image content negotiation.
- External footprint: brand searches, competitor "best mattress UAE" listicles, review platforms.

**Not measured:** Core Web Vitals field data and Lighthouse scores — the PageSpeed Insights API returned a quota-exhausted error (`429 RESOURCE_EXHAUSTED`) during this audit. Performance findings below are static-code indicators plus measured server timings, not lab or field scores.

## 3. SEO findings

### 3.1 Technical — healthy

| Check | Result |
|---|---|
| HTTPS | ✅ valid, HSTS-era redirects in place |
| `http://` → `https://` | ✅ 301 |
| `www` → apex | ✅ 301 |
| Canonicals | ✅ self-referencing on every template checked |
| `robots.txt` | ✅ well formed; blocks cart, checkout, search facets, `sort_by`, `filter` combos, `preview_theme_id` |
| `sitemap.xml` | ✅ index → products / collections / pages / blogs / articles + AR mirrors + agentic discovery |
| Sitemap hygiene | ✅ `lastmod` present, image sitemap entries with titles and captions |
| Indexability | ✅ no stray `noindex` found; no `robots` meta conflicts |
| TTFB (3 runs) | ✅ 66 ms / 127 ms / 137 ms — very fast origin |
| HTML→text ratio | ⚠️ 265 KB HTML for ~1,400 words of homepage copy |
| Image format | ✅ CDN negotiates `image/webp` (110 KB hero at 1400 px) |
| Lazy loading | ✅ 46 of 48 homepage images |

**Concerns**

1. **Cloudflare rate-limiting is aggressive toward non-browser clients.** Repeated requests returned `429` with `Retry-After: 60`, then `403` browser-verification, on `/products/*` and `/collections/*` — while `/` and `/pages/*` stayed open. Googlebot, GPTBot, ClaudeBot, PerplexityBot and OAI-SearchBot all received `200` at the time of testing, so this is not currently blocking AI crawlers, but a crawler that exceeds the budget on a 68-product catalogue will see intermittent errors. Worth confirming with Shopify/Cloudflare bot settings that verified search and AI crawlers are exempt.
2. **Trailing-slash duplication.** `https://mayfhome.com/collections/mattresses/` returns `200` rather than redirecting to the non-slash canonical. Low risk (canonical is self-consistent) but it is a crawl-budget leak on 100+ URLs.
3. **Heavy front end.** 43 `<script>` tags, 98 KB of inline JavaScript, 7 stylesheets, 14 KB inline CSS, plus Judge.me, Microsoft Clarity, TikTok pixel, Meta pixel and an Azure Front Door endpoint. Only one `preload` and one `preconnect`. This is the main reason mobile Core Web Vitals are at risk — but *measure before optimising*, the origin is fast and Shopify's CDN caches well.

### 3.2 On-page

**Working well.** Collection and product titles are genuinely good and keyword-led, not template dumps:

- `Buy Mattresses Online UAE | All Sizes | MAYF Home` (49 chars)
- `Luxury Pillow Top Hotel Mattress UAE | Signature | MAYF Home` (60 chars)
- `Best Mattress for Back Pain UAE (2026 Guide) | MAYF Home` (56 chars)
- Meta descriptions are 124–157 characters, benefit-led, with prices and geography: *"34 cm pillow top over zoned pocket springs … free UAE delivery."*

**Gaps**

| Issue | Evidence | Impact |
|---|---|---|
| Missing meta description | `/pages/finder` — title `Find Your Mattress \| MAYF Home`, description `NULL` | Medium — this is a linked "help me choose" page |
| Brand casing inconsistency | Homepage title uses `MAYFHOME`; PDPs use `MAYF Home`; some collection titles render `Mayf home`; schema name is `Mayf home` | High for entity recognition — four spellings of one brand across one site |
| Thin product copy | Signature Hotel Collection PDP: ~60 words of description + 4 bullets, 6 H2s that are all footer headings | High — no room to rank for material/firmness/size long tail |
| No content H2 structure on PDPs | Only one H3 in body (`Need help choosing?`) | Medium — tabbed description hides structure from parsers |
| Empty `alt` attributes | 17–19 per page (logo, decorative, but also some product imagery) | Low–medium |
| Duplicate/near-duplicate products | `kids-latex-mattress-by-mayf-home` vs `mayf-kids-latex-mattress`; `mayf-kids-organic-latex-mattress` vs `mayf-pure-organic-latex-mattress` (both AED 2,850); `blackout-curtains-made-to-measure` vs `blackout-and-sheer-curtains-made-to-measure` | Medium — cannibalisation, near-identical PDPs competing |
| Dev artifact shipped | `EMPTY DOM REMOVE PROTECTOR` present in every page's DOM (hidden div) | Cosmetic, but it is a QA tell |
| No `About` / no author / no team page | Pages sitemap has contact, policies, services, tools — no company or people pages | High for E-E-A-T and for AI entity grounding |

### 3.3 Content assets — uneven, with two standouts

**Best page on the site: `/collections/curtains`.** Per-window price tables by width, a blind-vs-curtain comparison table, a room-by-room recommendation table, "Last updated November 2026", 10 FAQs including an explicit *"Is there a MAYF Home curtain shop near me?"* answer. This is exactly the shape of content that wins both classic SERPs and AI answers. **Use it as the template for mattresses.**

**Second best: the blog article `/blogs/sleep-home-guides/best-mattress-for-back-pain-uae`** — 1,360 words, opens with a bolded **Short answer**, has a firmness-by-sleeping-position table, a product comparison table with prices, a "When to see a doctor" section (credibility), and 6 FAQs. Genuinely good GEO writing.

**Weakest: `/collections/mattresses`** — one 50-word intro paragraph, then a product grid, then "Still confused?". The highest-value commercial page in the catalogue is the thinnest.

**Corpus size is the constraint:** 5 articles total, all dated late 2026. For a category where AI engines need 10–20 corroborating pages to trust a source, this is a rounding error.

### 3.4 International

Full Arabic market (`/ar`), translated titles, translated meta descriptions, Arabic collection copy — not machine-dumped. `hreflang` correct in all three directions (`ar`, `en`, `x-default`) on every template checked, including product and article pages, pointing at `/ar/products/...` equivalents. Arabic pages are being indexed and served with Arabic snippets in search.

**One gap:** Organization schema on `/ar` still says `name: "Mayf home"` in Latin script with no `alternateName` in Arabic. Add the Arabic brand name.

## 4. AIO findings (AI Overviews, ChatGPT, Perplexity, Copilot)

### 4.1 Access — excellent

| Crawler | Status |
|---|---|
| GPTBot | ✅ 200 |
| OAI-SearchBot | ✅ 200 |
| ClaudeBot | ✅ 200 |
| PerplexityBot | ✅ 200 |
| Googlebot | ✅ 200 |

No `GPTBot`/`CCBot`/`Google-Extended` blocks anywhere in `robots.txt`. Content is server-rendered and readable without JavaScript. This is better than most Shopify stores.

### 4.2 Agentic layer — best-in-class, already done

- `/llms.txt` and `/agents.md` exist, describe the store to agents, list policies.
- `/.well-known/ucp` implements Universal Commerce Protocol v2026-08-25 with cart, checkout, catalog search, fulfillment, discount, buyer-consent capabilities and Google Pay / Shop Pay / card handlers.
- `sitemap_agentic_discovery.xml` is registered.

**But:** both `llms.txt` and `agents.md` are Shopify's generated boilerplate. They tell an agent *how to buy*, not *what the brand is, who makes it, what it is good at, or why it beats alternatives*. An LLM reading them learns nothing citable about mattresses. This is the single cheapest AIO upgrade available: add a brand-facts block — founded, location, materials, certifications, warranty, trial, delivery footprint, price bands, differentiators.

### 4.3 Extractability — good where content exists

Answer-friendly patterns already in use: "Short answer" lead-ins, Markdown-style tables, FAQ blocks, explicit price statements with currency and date. The curtains collection and the back-pain article are directly quotable.

**What breaks machine reading:**

| Issue | Where | Why it matters |
|---|---|---|
| No `Article` / `BlogPosting` schema | all 5 articles | No author, no `datePublished`/`dateModified`, no publisher → weaker recency and attribution signals |
| No `FAQPage` schema on pages that have FAQs | curtains collection, PDPs (Q&A block), blog articles | Visible FAQ text with no markup; the homepage is the only page with FAQPage |
| No `ItemList` on collections | 38 collection pages | Product grids are untyped; AI has to infer the set |
| Product entities incomplete | PDPs | `ProductGroup` has name/image/description/brand but **no `sku`**, no `aggregateRating`, no `review`; variant `Product` nodes have `offers` but no `sku` |
| No `WebSite` + `SearchAction` | site-wide | No sitelinks searchbox, weaker site-entity signal |
| No `LocalBusiness` | site-wide | Business serves 7 emirates with in-home service, addresses only in `Organization.address.region: "Ajman"`, no street address, no geo, no opening hours |
| `Organization.logo` missing | site-wide | Logo is a strong knowledge-panel input; `sameAs` (4 social profiles) is present but logo is not |

## 5. GEO findings (generative engine optimisation / brand authority)

This is the weak axis, and it has nothing to do with the website's code.

### 5.1 The citation gap

A search for the exact category query AI engines answer — *"best mattress in UAE 2026"* — returns:

- [altftool brand rating](https://www.altftool.com/brandrating/home-and-lifestyle/mattresses) — 10 brands ranked, MAYF absent
- [Luxury Lifestyle "Top 7 Luxury Mattress Stores in Dubai"](https://luxurylifestyle.com/headlines/top-luxury-mattress-brands-in-dubai.html) — absent
- [radyinterior "5 Best Mattress & Bed Brands in UAE"](https://radyinterior.ae/best-mattress-brands-uae/) — absent
- [r/dubai "Best Mattress in UAE"](https://www.reddit.com/r/dubai/comments/1gpftkp/best_mattress_in_uae/) — absent (and Reddit is one of the highest-weight sources for AI commercial answers)

Searches for the brand itself surface only:
- `mayfhome.com` own pages (indexed, with Arabic pages showing `srsltid` — so the Merchant Center feed is live and driving impressions), and
- Instagram `@mayf.home` and a Facebook page.

**No third-party mentions at all** were found: no review sites, no press, no comparison articles, no forum threads, no directory listings, no Google Business Profile surfaced. When a shopper asks an AI "what's a good mattress brand in Dubai under AED 2,000", there is nothing outside mayfhome.com for the model to corroborate a claim with. Models overwhelmingly recommend brands they have seen *discussed*, not brands with the best schema.

### 5.2 Trust signals an AI cannot find

| Signal | Status | Consequence |
|---|---|---|
| Customer reviews | Judge.me installed; **1 product shows 5.0 (1)**; signature mattress PDP says "Be the first to write a review" | No `aggregateRating`, no stars in SERP, no social proof to quote |
| Google Business Profile | Not found in search | Excluded from "near me" and Maps-based AI answers |
| About / founders / team | No such page | No entity grounding; AI cannot say who is behind the brand |
| Certifications | CertiPUR-US, OEKO-TEX, fire retardancy ("FR") are sold on but the certifications are not evidenced anywhere | These are exactly the verifiable facts AI cites for mattress recommendations |
| Third-party testing / "how we test" | None | Weak E-E-A-T for a health-adjacent purchase (back pain) |
| Press / awards | None found | No authority anchor |

### 5.3 Entity consistency

The brand appears as **MAYFHOME**, **MAYF Home**, **Mayf home**, and **mayfhome** within its own site — in `<title>`, in schema `name`, in body copy, and in the domain. For an LLM resolving entities, that is four weak signals instead of one strong one. Pick **MAYF Home** everywhere, use `alternateName` in schema for the variants, and add the Arabic name.

### 5.4 What is genuinely ahead of competitors

- Arabic-first content is rare among UAE mattress brands and is a real differentiator in Arabic-language AI answers.
- The agentic commerce stack (UCP + Shop skill + WebMCP) means MAYF can be *transacted with* by an AI agent, not just recommended. Almost no UAE competitor has this.
- The curtains pages are better structured than most competitors' entire sites.

## 6. Action plan

### Now — this week (schema and fixes, high certainty, low cost)

1. **Complete `Organization` schema**: add `logo` (absolute URL, ≥112×112), `alternateName: ["MAYFHOME", "Mayf Home", "مايف هوم"]`, street address, `foundingDate` if known. Add `WebSite` + `SearchAction` on the homepage.
2. **Add `LocalBusiness`** (or `Store`) with the Ajman address, `areaServed` for all 7 emirates, `openingHours`, phone — even though sales are online, service coverage is local.
3. **Add `FAQPage` to the pages that already have FAQs**: curtains collection, `/pages/curtains-service`, every PDP Q&A block, all 5 blog articles.
4. **Add `Article`/`BlogPosting`** with `author` (a named human), `datePublished`, `dateModified`, `publisher` → `Organization` on all 5 posts.
5. **Complete PDP product schema**: add `sku`/`mpn` to each variant, and `hasMerchantReturnPolicy` + `shippingDetails` at `ProductGroup` level (they exist only on variants). Add `aggregateRating` + `review` the moment reviews exist.
6. **Add `ItemList`** to the 38 collection pages.
7. **Add meta description to `/pages/finder`.**
8. **Unify the brand string to `MAYF Home`** in every title, schema `name`, and H1-adjacent copy. Remove `MAYFHOME` from the homepage title.
9. **Delete the `EMPTY DOM REMOVE PROTECTOR` div** from the theme.
10. **Rewrite `llms.txt` / `agents.md`** with a brand-facts block: what MAYF sells, price bands, warranty, trial terms, delivery footprint, materials, certifications, and what makes it different. Keep Shopify's commerce instructions below it.
11. **Merge the duplicate products** (kids latex pair, organic latex pair) with 301s to the surviving URL.

### Next — 30 days (content depth, the SEO lever that compounds)

12. **Rebuild `/collections/mattresses` on the curtains template**: price-by-size table, firmness guide, "which mattress for which sleeper" table, 8–10 FAQs, `Last updated` line.
13. **Expand PDP descriptions to 300–500 words** with real H2/H3 structure (not tabs): construction layers, firmness out of 10, who it suits, size guide, care, delivery — then link to the matching blog guide.
14. **Publish an About page** with the company, the people, the sourcing story, and the Ajman operation. Add author bios to the blog.
15. **Evidence the claims.** Add a page or section documenting CertiPUR-US / OEKO-TEX / FR compliance with certificate references. These are the facts AI cites.
16. **Review engine on.** Judge.me is installed but empty. Post-purchase review request flow, seeded with the existing customer base, targeting 25+ reviews on the 3 hero SKUs. This unlocks stars in SERP *and* quotable social proof.
17. **Build the comparison content AI actually retrieves**: "MAYF Home vs Silentnight", "MAYF vs Sleepwell", "pocket spring vs memory foam in UAE heat", "mattress prices in Dubai: what AED 1,000 / 2,000 / 3,000 buys". Ten to fifteen pieces, each with a table and a short answer.

### Later — 90 days (GEO authority, the real bottleneck)

18. **Get into the listicles.** Pitch the 4 ranking pages above (altftool, Luxury Lifestyle, radyinterior, sleepmod) with product samples and spec sheets. A single placement in a page AI already cites is worth more than 20 blog posts.
19. **Own Reddit and Quora.** r/dubai and r/UAE mattress threads are permanent, high-weight AI sources. Participate honestly as a UAE brand, answer spec questions, don't spam links.
20. **Google Business Profile** — create/claim it, even as an online-first retailer with service coverage. It anchors the entity for Maps-based AI answers and for branded search.
21. **Digital PR**: UAE home/interiors publications (Khaleej Times home sections, Gulf News, Harper's Bazaar Arabia home, Identity, Love That Design) — data-led pitches: "what UAE households actually spend on mattresses", "how humidity affects mattress life in the Gulf". Citable statistics earn links *and* AI quotations.
22. **Measure it.** Track branded search volume, AI-referral traffic (chatgpt.com, perplexity.ai, copilot.microsoft.com referrers in GA4), and a fixed set of 20 prompts run monthly across ChatGPT/Perplexity/Gemini ("best mattress Dubai under 2000", "ماهي أفضل مرتبة في الإمارات") to see whether MAYF is named.
